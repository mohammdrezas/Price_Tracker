# رهگیر قیمت اکانت‌های بازی PlayStation

یک ابزار خودکار که قیمت اکانت‌های بازی PS را در چند فروشگاه اینترنتی رهگیری می‌کند و هر وقت قیمتی افت کند در تلگرام به شما خبر می‌دهد — تا بهترین زمان خرید را از دست ندهید.

## معرفی

قیمت اکانت‌های بازی PS4 و PS5 مدام تغییر می‌کند و از فروشگاهی به فروشگاه دیگر هم تفاوت زیادی دارد، به همین خاطر چک‌کردن دستیِ هر فروشگاه در هر روز خسته‌کننده است. این پروژه این کار را به‌صورت خودکار انجام می‌دهد: به صفحه‌ی محصول‌ها سر می‌زند، قیمت و وضعیت موجودیِ فعلی را جمع می‌کند، تاریخچه‌ی آن‌ها را در طول زمان نگه می‌دارد، و هر وقت یک بازی نسبت به میانگین اخیرش به‌طور محسوسی ارزان‌تر شد به شما اطلاع می‌دهد.

## قابلیت‌ها

- رهگیری چند فروشگاه (game-center و xgames) از روی یک لیست محصول در دیتابیس
- اسکرپ همزمانِ همه‌ی محصول‌ها با برنامه‌نویسی ناهمگام (asyncio + aiohttp)
- پاک‌سازی متنِ درهم‌ریخته‌ی قیمت (پشتیبانی از ارقام فارسی و انگلیسی و حذف واحد پول)
- نگهداری تاریخچه‌ی کامل قیمت در SQLite برای تحلیل زمانی
- تشخیص خودکار افت قیمت با مقایسه‌ی آخرین قیمت با میانگین اخیر
- ارسال هشدار به تلگرام (و ترمینال)
- اجرای خودکار روزانه از طریق زمان‌بندِ سیستم

## چطور کار می‌کند

جریان کلی کار به این صورت است:

```
products → scrape → clean → store → analyze → alert
```

۱. لیست محصول‌های فعال (نام، فروشگاه و لینک) از جدول `products` در دیتابیس خوانده می‌شود.

۲. صفحه‌ی همه‌ی محصول‌ها به‌صورت همزمان و ناهمگام دانلود می‌شود تا زمان انتظار برای پاسخ سرورها روی هم بیفتد و کار سریع‌تر انجام شود.

۳. برای هر فروشگاه یک تابع تجزیه‌ی مخصوص وجود دارد که نام، قیمت و وضعیت موجودی را از صفحه بیرون می‌کشد؛ سپس قیمت تمیز و به عدد صحیح تبدیل می‌شود و کمترین قیمتِ بازه انتخاب می‌گردد.

۴. هر قیمت به همراه زمان دقیق ثبت، در جدول `price_history` ذخیره می‌شود تا یک تاریخچه‌ی زمانی ساخته شود.

۵. برای هر محصول، آخرین قیمت با میانگین قیمت در چند روز اخیر مقایسه می‌شود؛ اگر افت از یک حد مشخص بیشتر باشد، به‌عنوان فرصت خرید علامت می‌خورد.

۶. هشدارها به تلگرام (و ترمینال) ارسال می‌شوند.

## تکنولوژی‌ها

- **Python**
- **asyncio** و **aiohttp** — برای اسکرپ همزمانِ صفحه‌ها
- **BeautifulSoup** — برای تجزیه‌ی HTML و استخراج داده
- **SQLite** — برای ذخیره‌ی محصول‌ها و تاریخچه‌ی قیمت
- **python-dotenv** — برای نگهداری امنِ توکن‌ها در فایل `.env`
- **requests** — برای ارسال پیام به API تلگرام
- **pytest** — برای تست‌ها

## راه‌اندازی

۱. مخزن را clone کنید و وارد پوشه‌ی آن شوید.

۲. یک محیط مجازی بسازید و فعالش کنید:

```
python -m venv .venv
.venv\Scripts\Activate.ps1
```

۳. کتابخانه‌های موردنیاز را نصب کنید:

```
pip install -r requirements.txt
```

۴. یک فایل `.env` بر اساس `.env.example` بسازید و توکن ربات و شناسه‌ی چت تلگرام خود را در آن بگذارید:

```
TELEGRAM_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
```

۵. دیتابیس را بسازید و محصول‌های اولیه را وارد کنید:

```
python -m database.db
python -m database.seed_products
```

## استفاده

برای اجرای یک‌باره‌ی کل فرایند:

```
python main.py
```

با این دستور، برنامه همه‌ی محصول‌های فعال را اسکرپ می‌کند، قیمت‌ها را ذخیره می‌کند، افت قیمت را بررسی می‌کند و در صورت وجود، هشدار می‌فرستد.

## اجرای خودکار (زمان‌بندی)

برای اینکه برنامه هر روز به‌صورت خودکار اجرا شود، از زمان‌بندِ سیستم‌عامل استفاده کنید.

در ویندوز با Task Scheduler یک تسک روزانه بسازید که فایل `run.bat` را اجرا کند (به‌جای مسیر نمونه، مسیر واقعی پروژه‌ی خودتان را بگذارید):

```
schtasks /create /tn "PriceTracker" /tr "C:\path\to\project\run.bat" /sc daily /st 10:00
```

در لینوکس یا مک می‌توانید با cron یک خط به crontab اضافه کنید (اجرای روزانه ساعت ۱۰ صبح):

```
0 10 * * * /path/to/project/.venv/bin/python /path/to/project/main.py
```

## تست‌ها

برای اجرای تست‌ها:

```
python -m pytest
```

## کارهای آینده (Future Work)

- **افزودن خزنده (Crawler):** در حال حاضر لینک محصول‌ها به‌صورت دستی به دیتابیس اضافه می‌شوند. در قدم بعدی می‌توان یک خزنده اضافه کرد که با گرفتن آدرسِ یک صفحه‌ی دسته‌بندی، خودش لینک همه‌ی بازی‌ها را پیدا کرده و به دیتابیس اضافه کند.
- **پشتیبانی از فروشگاه‌های بیشتر:** به‌لطف ساختار رجیستریِ parserها، افزودن یک فروشگاه جدید فقط به نوشتن یک تابع تجزیه‌ی تازه و افزودن یک خط به دیکشنری نیاز دارد.
- **ذخیره‌ی لاگ در فایل:** در حال حاضر لاگ‌ها در ترمینال نمایش داده می‌شوند؛ می‌توان آن‌ها را در یک فایل هم ذخیره کرد.
- **مدیریت دقیق‌تر قیمت:** به‌جای فقط کمترین قیمت، می‌توان کمترین و بیشترین قیمتِ بازه یا نسخه‌های مختلف یک بازی را جداگانه رهگیری کرد.
- **نمایش نموداری:** ساخت یک داشبورد ساده برای دیدنِ روند قیمت هر بازی در طول زمان.
